# EconLab 101｜經濟決策實驗室

以 **Bade／Parkin《基礎經濟學》中文第三版**為課程導航，將教科書章節轉化為可直接授課、可自行學習、可操作模型、可完成 PBL 的互動式 open course。

目前 repository 提供第一個可操作的垂直切片 MVP：

> **CH04 需求與供給｜演唱會票價危機**

學生先面對「官方低票價是否真的比較公平」的決策，再依序理解需求、供給、短缺、過剩與市場均衡，最後替虛構音樂祭設計票務制度並撰寫政策備忘錄。

## 直接體驗

MVP 是零相依的單頁應用。下載後可直接開啟 `index.html`，或在 repository 根目錄執行：

```bash
python3 -m http.server 4173
```

再瀏覽：

```text
http://localhost:4173
```

GitHub Pages workflow 採手動觸發，避免每次 push 都消耗 Actions 額度。啟用後預期網址為：

```text
https://yhlai0911.github.io/econlab-101/
```

## MVP 已包含

- **六幕式學習旅程**：決策現場、需求解碼、供給解碼、均衡實驗室、衝擊挑戰、PBL 政策室。
- **自學模式**：短單元、先預測、立即回饋、瀏覽器本機進度保存。
- **授課模式**：教師提示、課堂計時器、鍵盤左右鍵切換場景。
- **動態供需模型**：調整票價、需求熱度與供給容量，即時呈現需求量、供給量、均衡價格及短缺／過剩。
- **情境衝擊**：歌手爆紅、加開場次、場租上升等事件的曲線判斷。
- **PBL 決策**：比較低價實名抽籤、動態定價、雙軌混合票制與會員優先制度。
- **響應式介面**：桌面三區授課畫面與手機底部旅程導航。

## 教科書與內容治理

平台以教科書章節作為**課程覆蓋與閱讀導航**，但不把出版社教師配件公開搬上網站。MVP 的文字、情境、數值、SVG 圖形、互動程式、練習與 PBL 任務均為原創示範。

出版社投影片、教師題庫、習題解答與受保護圖片均未納入公開 repository。
