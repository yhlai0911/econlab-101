# EconLab 101｜經濟決策實驗室

以 **Bade／Parkin《基礎經濟學》中文第三版**為課程導航，將教科書章節轉化為可直接授課、可自行學習、可操作模型、可完成 PBL 的互動式 open course。

目前 repository 提供第一個可操作的垂直切片：

> **CH04 需求與供給｜演唱會票價危機**

## v0.2：初學者焦點版

第一版同時顯示學習地圖、主要內容、教師資訊與資料面板，對第一次接觸經濟學的學生而言，視覺與認知負荷過高。v0.2 將介面改為：

> **一個問題＋一個視覺＋一個操作＋一句結論**

主要調整：

- 移除學生畫面左右兩側的常駐欄位。
- 每次只呈現一個主要認知任務。
- 正式定義、方程式、課本對照改為需要時才展開。
- 教師提示、計時器與投影工具只在教師模式出現。
- 需求與供給各自只操作一種變化，再由頁籤切換另一種變化。
- 衝擊挑戰一次只顯示一則市場新聞。
- PBL 拆成「選優先目標 → 選制度 → 說明理由與代價」三步。
- 保留桌面、教室投影與手機直向版面。

## 六幕學習旅程

1. **決策現場**：低票價真的比較公平嗎？
2. **需求解碼**：需求量變動與需求變動。
3. **供給解碼**：供給量變動與供給變動。
4. **均衡實驗室**：短缺、過剩與均衡價格。
5. **衝擊挑戰**：一次判斷一則真實情境。
6. **PBL 政策室**：設計票務制度並說明取捨。

## 直接體驗

不需安裝前端套件。在 repository 根目錄執行：

```bash
python3 -m http.server 4173
```

再瀏覽：

```text
http://localhost:4173
```

GitHub Pages workflow 採手動觸發，避免每次 push 都消耗 Actions 額度。啟用後預期網址為：

```text
https://yhlai0911.github.io/econlab-101/
```

## 使用模式

### 學生自學

- 依「下一幕」完成短單元。
- 先預測，再操作模型與讀取回饋。
- 學習進度保存在瀏覽器本機。
- 需要時才展開正式定義與計算。

### 教師授課

從右上角選單切換教師模式，可使用：

- 每幕教學目的、建議追問與常見迷思。
- 課堂計時器。
- 鍵盤左右鍵切換場景。
- `F` 進入全螢幕投影。

## 教科書與內容治理

平台以 Bade／Parkin 第 4 章作為課程覆蓋與閱讀導航，但不把出版社教師配件公開搬上網站。MVP 的文字、情境、數值、SVG 圖形、互動程式、練習與 PBL 任務均為原創示範。

出版社投影片、教師題庫、習題解答與受保護圖片均未納入公開 repository。
