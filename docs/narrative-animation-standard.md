# EconLab 101｜敘事型教學動畫標準 v0.7

## 核心定義

EconLab 的動畫不是「把教材文字動起來」，而是用一個具有目標、衝突、轉折與結果的短篇故事，讓學生看見靜態文字或單張圖形難以呈現的經濟機制。

一支影片只有在符合以下命題時才成立：

> 拿掉這段動畫後，學生會失去至少一個必要的因果、時間、聚合、反事實或回饋推理步驟。

若靜態圖加三句文字即可完整取代，則不應製作動畫。

## 故事不是包裝

故事中的衝突必須由經濟限制產生，角色的選擇必須改變經濟狀態，結果也必須能由模型解釋。

每支 5–10 分鐘動畫採四段結構：

| 段落 | 敘事功能 | 認知功能 | 建議時間 |
|---|---|---|---:|
| 起 | 角色有目標，限制突然出現 | 激活既有直覺，要求第一次預測 | 45–90 秒 |
| 承 | 角色嘗試解決，機制逐步運作 | 把個別行動與抽象模型建立映射 | 2–3 分鐘 |
| 轉 | 原先直覺失敗或條件改變 | 製造可解釋的認知衝突與反事實比較 | 1.5–2.5 分鐘 |
| 合 | 角色重新決策並承擔代價 | 完成模型、說明邊界，立即遷移到新情境 | 1–2 分鐘 |

## 適合動畫的經濟概念

優先製作具有以下特性的概念：

1. **時間演化**：價格調整、庫存累積、政策時滯、景氣傳導。
2. **隱藏因果鏈**：能源成本如何進入企業決策，再聚合成 SRAS。
3. **個體到總體的聚合**：買家願付價格如何生成需求曲線。
4. **反事實**：選擇一個方案時，最佳被放棄方案如何構成機會成本。
5. **回饋迴路**：短缺、競價、進場與價格清算。
6. **狀態轉換**：企業由生產轉為停工、勞工由就業轉為失業。

純定義、分類或可由靜態對照表清楚完成的內容，應保留為書頁、圖解或練習，不為了畫面熱鬧而動畫化。

## 視覺敘事規則

### 1. 每一個動作都必須有經濟語意

角色、商品、金錢、時間籌碼、庫存、能源、訂單或勞工的移動，必須對應可命名的變數或狀態。

禁止：

- 無意義漂浮粒子。
- 只為填滿畫面的循環人流。
- 與旁白無關的圖示跳動。
- 文字飛入、旋轉或縮放作為主要畫面。
- 已畫好的曲線在沒有微觀機制時直接滑動。

### 2. 保留基準狀態與反事實

重要轉折後，不立即抹掉舊狀態。以淡色殘影、雙時間線、分割畫面或帳本保留：

- 改變前與改變後。
- 實際路徑與最佳替代路徑。
- 需求衝擊與供給衝擊。
- 短期政策效果與較長期效果。

學生必須能回答：

> 什麼改變？什麼保持不變？結果為何不同？

### 3. 具體世界與抽象模型同步生成

不能先演完故事，再切到一張曲線說「所以右移」。

正確做法是：

- 買家依願付價格逐一進場，右側同步留下需求點。
- 工人依相對生產力被重新配置，右側同步生成 PPF 點。
- 企業依成本與物價決定產量，右側同步生成 SRAS。

抽象模型必須是故事中個別決策的壓縮結果。

### 4. 文字只負責標示

- 單一畫面主要文字原則上不超過 12 個中文字。
- 公式只在對應機制已可見後出現。
- 不讓旁白逐字顯示成大段字幕投影片。
- 字幕放在固定安全區，不搶奪主要視覺。

## 學習互動節奏

### 影院模式

完整連續播放，不強制中斷故事。適合學生第一次觀看與教師投影。

### 互動模式

只在自然的故事段落邊界暫停，最多三次：

1. **起之後**：預測角色的選擇或結果。
2. **轉之前**：預測條件改變後的機制。
3. **合之後**：換一個表面情境做遷移。

不得每 30 秒彈出選擇題，避免破壞敘事沉浸與工作記憶中的因果鏈。

## 聲音設計

### 角色與旁白

- 角色以簡短對話推動衝突。
- 旁白只補充看不見的推理，不重複畫面。
- Gemini TTS 分角色、分場生成；正式產出前先以無聲 animatic 驗證機制。

### BGM

Lyria BGM 必須隨故事弧線服務：

- 起：好奇與目標感。
- 承：穩定、低密度，為機制留空間。
- 轉：短暫提高張力。
- 合：收束而非煽情。

在公式推導、預測停點、錯誤診斷與重要因果揭露時，BGM 降低或完全停止。

## 製作順序

1. 學習目標與常見迷思。
2. 一句話故事命題。
3. 角色目標、限制、轉折與決策代價。
4. 無聲分鏡與 animatic。
5. 經濟機制與模型一致性測試。
6. 初學者認知走查。
7. 互動停點與遷移題。
8. 角色台詞與旁白。
9. Gemini TTS。
10. Lyria BGM 與音效。
11. HyperFrames／其他免費工具正式渲染。
12. 教師與學生測試。

## 發布閘門

每支動畫在發布前必須全部通過：

- [ ] 有可獨立敘述的角色、目標、衝突、轉折與結果。
- [ ] 經濟限制是故事衝突的成因，不是事後附加解說。
- [ ] 至少揭露一個靜態圖不易呈現的必要機制。
- [ ] 每個主要動作皆對應經濟變數、狀態或決策。
- [ ] 具體行動與抽象模型同步生成。
- [ ] 保留基準狀態或反事實。
- [ ] 關閉旁白後，主要因果鏈仍可辨認。
- [ ] 學生在轉折前必須作出可被推翻或修正的預測。
- [ ] 結尾有新情境遷移，不只重述原故事。
- [ ] 影院模式可不中斷播放，互動模式最多三個自然停點。
- [ ] 文字不是主要運動畫面。
- [ ] 經濟學者可逐幀指出模型假設與變數映射。

## 最終判準

> 好動畫不是讓學生看見更多東西在動，而是讓原本看不見的經濟形成過程變得可觀察、可預測、可解釋、可遷移。
