# v0.6 開發狀態

## 已完成

- CH03、CH04、CH19 三種不同動畫引擎。
- 角色、物件、交易、粒子、成本波與政策傳導的 deterministic timeline。
- 每章 5–7 分鐘完整 composition，可播放、暫停、倒帶、調速與精準 seek。
- 左文右動畫互動書頁；手機使用相同內容、題目、模型與動畫，只重新排列。
- 每章 3 個概念展頁、6 題核心練習與 8 題章末遷移題。
- Gemini 3.1 Flash TTS、Lyria 3、FFmpeg 與 HyperFrames adapter／script。

- 模型、題庫、瀏覽器與手機排版自動驗證。
- 三支 8 秒靜音 proof clips，證明動畫是物件與機制運動，而非動態文字投影片。
