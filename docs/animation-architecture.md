# 真正動畫的章節架構

## 1. 三層共用狀態

每章不應各自維護「網站數字、影片數字、題目答案」三套內容。目標架構是：

```text
Economic model state
        ├── animation composition
        ├── interactive model
        ├── worked example
        └── assessment feedback
```

v0.6 已先以一致方程式與測試維持同步；正式擴展時應抽成 `econ-core` 套件。

## 2. Deterministic timeline

`assets/animation-runtime.js` 提供：

```js
window.renderSeek(seconds)
window.__renderReady
window.__econAnimation
```

任何時間 `t` 的畫面只依賴 `t` 與模型參數，不依賴前一幀。這使動畫可以：

- 暫停、倒帶與跳轉；
- 由 HyperFrames 逐幀擷取；
- 用測試直接檢查某時間點的幾何與狀態；
- 重複渲染得到相同畫面。

## 3. 三種動畫引擎

### CH03：概念選擇型

動畫主體：

- 人物在讀書、打工、休閒間移動；
- 56 個可配置時間以籌碼方式落入用途容器；
- 選擇滑塊與 PPF 點同步；
- 生產投入進入兩部機器；
- 報表與海報箱跨人交換。

學習功能：把「稀少性、機會成本、PPF、比較利益」從定義轉成可見取捨。

### CH04：微觀市場型

動畫主體：

- 買家流向固定容量場館；
- 排隊人數與二手價格改變；
- 價格點沿需求曲線移動；
- 偏好衝擊使曲線平行右移；
- 價格點依新方程式重算並停留在新曲線；
- 場館容量隨時間範圍展開；
- 買家、賣方與票券向市場撮合區移動；
- 票務制度重新配置歌迷與抽籤球。

學習功能：呈現市場形成價格的機制，不只移動兩條線。

### CH19：總體系統型

動畫主體：

- 家庭、企業、銀行、政府及國外間的貨幣、商品與信用流；
- C／I／G／NX 流向產出；
- AD 衝擊後均衡移動；
- 能源粒子減速、成本波擴散、員工離開；
- SRAS 左移後物價上升、產出下降；
- 政策槓桿、傳導箭頭及時滯時鐘改變。

學習功能：把總體經濟從靜態兩曲線圖，還原成相互連動且存在時滯的系統。

## 4. 手機與桌面

手機不另製刪節版。相同內容與 composition 只改變版面：

- 桌面：左文右動畫；
- 手機：文字、動畫、立即題依同一 learning beat 緊鄰排列；
- 動畫保持完整 16:9 構圖，不以裁切假裝響應式；
- 未來正式版本可由同一模型額外輸出 9:16 composition，但學習順序與題目不變。
